# DensityToSZ(): source audit, derivation and potential-level validation

Generated by `write_reports.py` from `potential_validation_summary.json`, `potential_validation.csv`, `first_order_check/` and `experiment_manifest.json`. The tested code is the real compiled `DensityToSZ()` from `libfac.a` of the experimental build (FAC source `603c0e5358`, flags `-O2 -fPIC`, no workaround flag), called through the C harness `harness/densitytosz_harness.c` on FAC's own radial grid.

## 1. Source audit (the source and the binary are the authority)

Call path in the SCF (`faclib/radial.c`, `faclib/orbital.c`):

```
OptimizeRadial -> OptimizeILoop (each SCF iteration) -> SetPotential(acfg, iter)           radial.c
  -> PotentialHX -> PotentialHX1                                                           radial.c
       DensityToSZ(potential, potential->NPS, u, ue1, &jps0, 0)   [orbital.c, v2 kernel]    <- direct potential, every iteration
       SetPotentialPS(...)           ZPS = Z(r)(1 - exp(-r/dps))  (nuclear Debye term)
  PotentialHX: u = u0 - ue  (direct minus exchange), optional csi/ihx asymptotic-charge adjustment
  SetPotential: U(r) = (u - Z - Vc r)/r = u/r ;  SetPotentialU ; SetPotentialVT: VT = Vc + U + ZPS/r
```

| question | answer from the source and the harness |
|---|---|
| density passed in | `potential->NPS` = sum over shells of `nq (P^2 + Q^2)`: the radial density with integral `D dr = N`. In Debye mode (`mps = 1`) all electrons are in this one density (`N = NC` in the potential header, e.g. 24 = 24 for Fe III); the second, valence-only call is skipped. The harness confirms the convention: `r V(r_max)` of the Coulomb path equals N to 3e-7 N (the quadrature floor). |
| grid and quadrature | `rho = a r^q + b ln r` with unit index steps, `rad[0] = r_min ~ 4e-8 a0`, `rad[maxrp-1] ~ 1009 a0` (1500 points); integrals are cumulative cubic-spline quadratures in `rho` (`NewtonCotesIP`) of `D dr/drho`; the origin segment uses `D0 r0/3`. |
| returned array | `z = r V_H(r)` (positive for a positive density, atomic units), `jps = int_{r0}^inf D exp(-mu t)/t dt` (matches the reference, 2e-7 relative, = the Coulomb-path quadrature floor). |
| conversion to the effective potential | `u = z - zx` (direct minus exchange), `U = u/r` (the Coulomb `-Z/r` pieces cancel in `SetPotential`), added to `Vc` and `ZPS/r` in `SetPotentialVT`. |
| same mu everywhere | `EEScreenMu() = 1/dps` when `radial:ee_screen = 1`, `mps = 1`, `dps > 0`; `GetYkDebye` (screened Slater integrals) calls the same `EEScreenMu()`, and the nuclear term uses the same `dps`. The harness reports `EEScreenMu = 0.1000000000000033` for the requested 0.1. |
| gating, unscreened path | `mu > 0` selects the screened kernel; otherwise the original statements run verbatim. Bit-identical to the pristine upstream library (Test A). `ee_screen = 0` with the plasma on gives `EEScreenMu = 0` and the same Coulomb result. NaN, negative or infinite mu aborts. |
| outer integral and tail | the screened integrals are accumulated in blocks of exponent span `mu dr <= 100` with scaled integrands, so nothing overflows; the outer integral starts from zero at the last grid point (density beyond `r_max` is neglected, as in the Coulomb path). |
| used in every SCF iteration | yes: `DensityToSZ` runs inside `PotentialHX1` on each `SetPotential`, i.e. in every iteration; the A/B energies and the asymptotic charge (0 for B, N-1 for A) prove the orbitals respond to it. |
| not screened | local exchange, Breit and QED terms. The `csi`/`ihx` block in `PotentialHX` (below) was written for a Coulomb tail. |

## 2. Derivation (independent of FAC)

With `w(r12) = exp(-mu r12)/r12` the angular integral over the direction of `r'` gives, exactly,
`int dOmega' w / (4 pi) = [exp(-mu|r-r'|) - exp(-mu(r+r'))] / (2 mu r r')`, hence for a spherical density with `int D dr = N`

`r V(r) = int_0^inf D(r') [exp(-mu|r-r'|) - exp(-mu(r+r'))] / (2 mu r') dr'`.

For `r' < r` the kernel `[...]/(2 mu r')` equals `exp(-mu r) sinh(mu r')/(mu r')`; for `r' > r` it equals `exp(-mu r') sinh(mu r)/(mu r')`. Therefore

`r V(r) = exp(-mu r) int_0^r D sinh(mu r')/(mu r') dr' + r [sinh(mu r)/(mu r)] int_r^inf D exp(-mu r')/r' dr'`,
which is the expression of the task, and equals the `k = 0` Yukawa multipole `mu i_0(mu r<) k_0(mu r>)`. For `mu -> 0` it becomes `int_0^r D + r int_r^inf D/r'`. FAC's `E(x) = (1 - exp(-2x))/(2x) = exp(-x) sinh(x)/x` is the same function written without `sinh` (identity checked below), so `z = A~ + r E(mu r) B~` with `A~ = exp(-mu r) int D sinhc`, `B~ = exp(mu r) int D exp(-mu r')/r'`.

Two reference evaluators, neither using FAC's integrator or grid: (1) exact closed forms for densities `sum c r^m exp(-beta r)` in 80-digit `decimal` arithmetic; (2) 16-point Gauss-Legendre quadrature of the direct-kernel form above in float64 (no multipole expansion, no sinh). They agree with each other to <= 4e-07 of the peak, so the references are valid.

Test densities (normalised, `D = N (2a)^(2k+1)/(2k)! r^2k exp(-2ar)`): compact 1s-like (N=2, a=13), valence (N=6, k=2, a=1), diffuse (N=1, a=0.06, so `2a < mu` for mu >= 0.12), multishell Fe III-like (N=24). Tolerances were fixed before the first comparison (see `potential_validation.py` header).

## 6. Test D: numerical stability

* `E(x) = -expm1(-2x)/(2x)` equals `exp(-x) sinh(x)/x` (80-digit reference) to 1.1e-16 relative for x from 1e-12 to 5000; `E(0) = 1` is explicit; the source text of `_ee_E` was matched by regex: True.
* mu = 5 (`mu r_max = 5000`) and mu = 1e-10 (nearly Coulomb): all outputs are finite for all four densities (no overflow or NaN).
* The block-scaling constant (span 100) causes no visible error in the contributing region (Tests B, C).

## 7. Test E: physical consistency

* The screened direct potential is repulsive (positive) wherever representable and never exceeds the Coulomb one, for every density at mu = 0.1, 0.25, 1 (all PASS); far from the density it is a small fraction of the Coulomb value (e.g. 0.13 at the first grid point beyond 20 a0 for mu = 0.1).
* One-electron Fe XXVI: no electron-electron direct contribution; with nuclear screening the energy shifts by +70.5484 eV (mu = 0.1) and +175.6213 eV (0.25), independent of mu_ee (identical for cases A/B and C/D), matching an independent Dirac-Yukawa solver to 5e-4 eV.
* The screened Slater pathway stays active when the direct-potential modification is removed: the electron-electron screening effect on the Fe XVII energy is -120.5816 eV in the Coulomb-direct build (variant A) and -120.5824 eV in the screened build (B); nuclear-only runs are bit-identical in both builds (`results/physical_checks/`).

## 8. Exact first-order Debye-Hückel check of the screened total energy (outside DensityToSZ, but decisive for interpretation)

To first order `exp(-mu r)/r = 1/r - mu`, so for any normalised wavefunction `dE = mu (N Z - N(N-1)/2)` Hartree. Deviation of FAC's `E(mu) - E(0)` from it (%):

| ion | A mu=0.001 | A 0.003 | A 0.01 | B mu=0.001 | B 0.003 | B 0.01 |
|---|---|---|---|---|---|---|
| Fe XXVI (1s) | -0.00% | -0.01% | -0.03% | -0.00% | -0.01% | -0.03% |
| Fe XXV (1s2) | -0.01% | -0.01% | -0.03% | -0.01% | -0.01% | -0.03% |
| Fe XVII (2p6, N=10) | -0.01% | -0.03% | -0.09% | -0.07% | -0.06% | -0.13% |
| Fe IX (3p6, N=18) | -0.02% | -0.05% | -0.16% | -0.20% | -0.21% | -0.27% |
| Fe III (3d6, N=24) | -0.05% | -0.06% | -0.17% | -1.21% | -1.10% | -0.78% |
| Fe II (3d6 4s, N=25) | -0.04% | -0.06% | -0.17% | -0.94% | -0.79% | -0.35% |

Variant A follows theory (second-order deviations); variant B falls short, increasingly with the electron number and the open 3d shell (-1.2% for Fe III at mu = 0.001). Setting `radial:csi = 0` removes the deficiency (Fe III: -0.02%). The `csi`/`ihx` block of `PotentialHX1` adjusts the potential towards the asymptotic charge N+ihx, a Coulomb-tail construct; it acts only where the screened Hartree potential still reaches N-1 (small mu): at mu = 0.1 and 0.25 `csi = 0` leaves the Fe II-IV energies unchanged (`results/csi_zero_diagnostic`). This is **not** an error of `DensityToSZ` (the potential-level tests pass); its origin inside the `csi` block is a lead, not a finding.

## 9. Criteria revisions after the first run (kept transparent)

The first run (`potential_validation_summary_first_run.json`) failed 20 checks. Inspection showed flaws in my tests, not in DensityToSZ: R1 the normalisation threshold (1e-9) was below FAC's own quadrature floor (use the declared 1e-6); R2 sup-norm continuity cannot be linear once `mu r_max >> 1` (use r <= 5 a0); R3 "residual drops 4x when the grid is doubled" fails for the pristine Coulomb path too (use screened <= 3x Coulomb floor); R4 "no plateau" demanded <1e-100 where `exp(-0.1*1009) ~ 1e-44` (use <1e-30 N); R5 positivity was tested where the double underflows to 0; R6 tail relative accuracy only where |ref| >= 2.2e-16 x peak; R7 diffuse at mu = 1 informational. The declared tolerances 1e-6 / 1e-5 were not changed, and the marginal diffuse mu = 0.25 failure stayed a failure.

## Verdict

`DensityToSZ()` implements the screened Yukawa Hartree potential correctly (closed form and independent quadrature agree to 1e-7..1e-8 of the peak on FAC's grid, bit-identical Coulomb path, exact `exp(-mu r)` decay with no artefact), with one pre-declared criterion marginally missed in the deep tail of an extreme density.
